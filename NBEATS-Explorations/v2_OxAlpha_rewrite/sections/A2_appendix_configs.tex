\section{Configuration List}
\label{app:configs}

This appendix enumerates the configuration files that drive every sweep
cited in the paper. All files live under \texttt{experiments/configs/} in
the released repository, and the per-run CSVs they generate ship alongside
them (Appendix~\ref{app:protocol:repro}). An earlier version of this paper
promised verbatim configuration files in its first appendix; that promise
is honored here with the representative protocol block of
Appendix~\ref{app:configs:yaml}, taken verbatim from the released file.

\paragraph{Sweep groups.} The 112-configuration comprehensive sweep
(sliding) and the 53-configuration curated paper-sample subset partition
into five groups, named per the variant taxonomy of
Section~\ref{sec:method_variants}: (i) the paper baselines N-BEATS-G and
N-BEATS-I+G at $S \in \{10, 30\}$ with the output activation off and on;
(ii) homogeneous frozen-basis-plus-trend stacks in the unified layout,
$S \in \{10, 30\}$, polynomial order $p \in \{3, 5\}$, backcast rank
$\{H, 2H\}$; (iii) alternating single-branch stacks pairing one polynomial
trend stack with one frozen-basis stack over the untruncated, AE-trunk, and
gated-AE trunks at the same depths; (iv) efficiency variants --- unified-layout
AE-trunk blocks with and without the learned gate, plus the three-way
variant adding a learned rank-$r$ generic branch --- at AE latent width
$d \in \{8, 16, 32\}$, ten stacks; and (v) generic controls: pure generic
stacks with AE trunks and weight sharing disabled. Every basis-carrying row
swept the historical four-family shortlist; family identity is provenance
only (Appendix~\ref{app:hyperparams:basisfamily}). Hyperparameter grids are
tabulated in Table~\ref{tab:sweep_grids}.

\subsection{Representative verbatim configuration block}
\label{app:configs:yaml}

The block below resolves a promise made in an earlier version of this
paper: that verbatim configuration files would ship with the appendix. It
is reproduced from
\texttt{experiments/configs/comprehensive\_m4\_paper\_sample.yaml} --- the
file that generated every faithful paper-sample number in this paper ---
and defines the protocol of Appendix~\ref{app:protocol:faithful}. The
excerpt is verbatim except that the descriptive header comments and two
non-ASCII glyphs inside inline comments are elided or transliterated for
encoding portability; the released file is authoritative.

\begin{verbatim}
protocol:
  sampling_style: nbeats_paper
  steps_per_epoch: 1000
  sampling_weights: uniform
  # N-BEATS paper uses period-specific Lh values:
  # Lh = 1.5H for Yearly and Quarterly, Lh = 10H otherwise.
  lh_multiplier:
    Yearly: 1.5
    Quarterly: 1.5
    Monthly: 10
    Weekly: 10
    Daily: 10
    Hourly: 10

training:
  active_g: false
  sum_losses: false
  activation: ReLU
  max_steps: 100000
  max_epochs: 150              # safety cap; early stopping fires first
  patience: 15                 # val-check units; fires at >= 1500 steps
  val_check_interval: 100      # validate every 100 steps
  min_delta: 0.001             # require 0.1% improvement to reset patience
  n_blocks_per_stack: 1
  share_weights: true
  loss: SMAPELoss
  optimizer: Adam
  learning_rate: 0.001         # paper: 1e-3 Adam default
  forecast_multiplier: 5       # paper ensembles L in {2H..7H}; middle
  batch_size: 1024             # paper 1024

lr_scheduler:
  type: multistep
  n_milestones: 10             # paper: halve LR every 10% of training
  gamma: 0.5                   # paper: factor 0.5 at each milestone

block_params:
  wavelet_type: db3

runs:
  n_runs: 10
  seed_mode: random

output:
  results_dir: experiments/results
  csv_filename: comprehensive_m4_paper_sample_results.csv
  save_predictions: false
\end{verbatim}

The plateau variant differs only in the scheduler stanza (plateau type with
factor 0.5, patience 3, cooldown 1, minimum rate $10^{-6}$); the
sliding-window sweep differs only in its protocol and schedule stanzas
(Appendix~\ref{app:hyperparams:sliding}). All three files ship unchanged in
the supplement, together with the run-harness entry points recorded in
their headers.
